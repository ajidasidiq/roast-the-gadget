## The roast

> My wireless earbuds never die together: one quits mid-sentence, the other dies while I'm apologising for it.

## What it does

`main.ts` writes that single original roast line to `/output/entry.txt`, after validating it: 1–200 characters, a single line, not only whitespace, no leading or trailing whitespace.

## How to run

Requires Node 22.18 or later. No dependencies, no network.

```sh
node main.ts
cat /output/entry.txt
```
